# تجربتي وما تعلمته في كورس Git (باثي) 🚀

من أهم ما تعلمته في كورس **Git** في باثي هو كيفية استخدام الأوامر الأساسية التي تساعد المبرمجين على تنظيم مشاريعهم وملفاتهم البرمجية باحترافية.

## 🛠️ أبرز الأوامر التي تعلمتها واستخداماتها


| `git init` | لتهيئة مجلد المشروع وإنشاء مستودع Git محلي جديد بداخله. |
| `git add .` | لإضافة جميع الملفات والتعديلات الجديدة وتجهيزها للحفظ. |
| `git commit -m "تعليق"` | لحفظ التغييرات في سجل المشروع مع كتابة وصف يوضح ما تم إنجازه. |
| `git branch -M main` | لتسمية الفرع الرئيسي للمشروع باسم `main` وتوحيده. |
| `git remote add origin [رابط المستودع]` | لربط المشروع المحلي بالمستودع على منصة GitHub. |
| `git push -u origin main` | لرفع الملفات والتعديلات من الجهاز إلى المستودع في GitHub. |
